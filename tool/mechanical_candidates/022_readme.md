# Pinball Universes — Production Batch 022

Chrono Citadel is now the target for a true **two-ball trap and mechanically triggered three-ball release**. Five transparent 2D sprite frames were created in matching world coordinates: lock housing states 0/1/2 plus a timed gate open/closed. The gate still uses the pre-existing real segment collision (127,457) to (273,457), not image pixels. When the gate opens, a descending ball can enter the visible mouth (198,505); the machine visibly holds two balls without losing lives, rearms the shooter and opens the vault when the **next real ball physically contacts the gate while closed**, releasing both stored balls. Each capture awards 300 points and the release objective awards 1,500 points, in addition to existing physical gate-hit points. The standard 12-hit multiball shortcut must be disabled only for Chrono Citadel so locked balls are required there.

This package retains original 368×368 SVG and PNG vault art, gate source images, runtime transparent PNGs, a generated QA preview, manifest of exact geometry, and source-generation script. It contains neither the user's original artwork from unrelated game Projects nor any paid assets. The original published game branch stays untouched until the developer candidate completes automated and browser QA.
